## Summary

- **Comparison coverage:** 7 studies explicitly contrast metaphor with literal language (Sun, Lago, Mao, Xu Liu, Frau, Togashi, Lai/CNS); Ting Liu compares metaphor with the paper’s “non-metaphor” translations; Yu studies metaphor generation without a literal-generation control.
- **Baselines:** No exact interval recurs. Sun uses −500–0 ms to target onset (subtraction, 1 study); Frau uses −600 to −200 ms before picture onset (relative change, 1); Ting Liu uses a 10-s circle reference (1). Lago instead uses resting-state normalization and a −500 to −10 ms pre-target feature window. Baseline details are n/a for Mao, Xu Liu, Togashi, and Lai/CNS; Yu reports within-participant Z-scoring without event-baseline subtraction.
- **Bands:** Alpha/upper alpha is the most recurrent named band (6/9: Lago, Yu, Xu Liu, Ting Liu, Frau, Togashi). Beta-family effects are reported by Xu Liu, Frau, and Lai/CNS. Sun reports delta and theta; Mao reports high-frequency variability without numeric limits.
- **ROIs:** Posterior/parieto-occipital findings appear in 3 studies (Sun, Frau, Togashi); frontal/frontocentral findings appear in 3 (Sun, Ting Liu, Lai/CNS). Lago uses source ROIs in TPJ and language cortex; Yu uses data-driven ICA/HMM patterns. Mao reports left-hemisphere connectivity; Xu Liu’s abstract gives no ROI.
- **Windows:** No exact metaphor–literal result window recurs. Sun reports peak-power-selected theta 170–260 ms and delta 430–530 ms; Frau’s cluster spans 0–2,000 ms; Ting Liu uses a 1-s output window before Enter. Lago models post-target time courses and uses −500 to −10 ms for pre-target alpha; other records report no numeric event window.
- **Statistics/window choice:** Frau is the only study explicitly using full time-frequency-sensor cluster permutation (1/9). Sun chooses intervals according to maximum power (data-driven); Yu uses a six-state HMM (data-driven). No consulted page explicitly labels a fixed metaphor–literal window as a-priori; a-priori status is otherwise n/a.
- **Production:** Three records analyse metaphor output/generation (Yu, Ting Liu, Togashi); only Yu lacks a literal-generation condition. Lai/CNS instead measures explanations after metaphor- versus literal-based tutoring.
