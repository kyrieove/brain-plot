# Survey: cluster-permutation result figures from papers that ran the test in BESA (2026-10-11)

Scope: sensor-space ERP/EEG/MEG cluster-permutation result figures only, where the methods text names BESA Statistics (or BESA Research's statistics module) as the software that ran the cluster test and the figure shows that result (no source-space, no time-frequency, no decoding); same scope as `survey.md`. Columns reuse `survey.md`'s column set and add `BESA evidence` (a <15-word methods quote naming BESA and the cluster test, plus the BESA version if stated) and `BESA-native display` (does the figure look like BESA Statistics' own output or was it re-drawn). Candidates were found with web search and Europe PMC full-text search (`"BESA Statistics"`, plus `cluster`/`permutation`), the BESA website's product/feature pages, and reading each candidate's BESA methods sentence plus figure caption; a row was kept only if the methods name BESA as the cluster-test software and its figure shows that result. Every DOI was resolved on Crossref (title + first author matched) and every image was downloaded from the publisher/PMC/CDN page and opened to confirm it is the right figure.

Rows: 27 = 24 papers + 3 BESA documentation pages. Papers that ran the cluster test in BESA: 24 (rows 1–24).

## Takeaways for the columns layout
- BESA users rarely publish a channel × time raster: the same cluster is shown as one difference topomap per significant cluster plus the ERP waveform at 1–2 representative electrodes (rows 1,2,5,7,8,13,14,15,17,20,21,23) — the raster has no direct counterpart in this corpus.
- Cluster electrodes are drawn as small boxes/squares over the map (rows 1,2,5,7,8,10,13,14,15,16,17,20,21,22,23); stars/asterisks for significance are printed inside or beside the box (rows 1,5,7,10,15,16,17,21,22).
- Every cluster carries a label: a number ("Cluster 1..4", rows 1,3,23) and/or a latency-range tag printed on the figure (rows 5,7,19,22).
- p-values / asterisks appear on the figure itself, not only in the caption (rows 5,7,15,17,21,22).
- The cluster topomap is coloured by the test statistic — t (rows 2,3,20) or F (rows 7,22) — separately from the µV amplitude maps (rows 1,4,8,17).
- ERP amplitude maps keep a diverging blue–white–red µV scale with thin contour lines (rows 1,3,8,10,14,16,23) — the same scale brain-plot's topomap row uses.
- When the effect is long or stimulus-driven, BESA users replace the raster with a topomap series at fixed latencies (rows 6,16,18,22,24) — the nearest analogue to brain-plot's 8-bin topomap row.
- Waveforms are drawn only for a representative electrode chosen from the cluster (rows 1,3,8,10,13,17,20,21), not for all channels.
- Significance on the waveform is a filled band (grey/pink/blue) for a window (rows 4,5,6,9,10,12,14,15,17,21) and/or vertical dashed lines at the cluster edges (rows 13,23,24).
- Cluster outlines on the topomap are connected box rows/squares (rows 8,14,15,20,21) or a masked contiguous region of the statistic (rows 7,16,19,22).
- The vendor's own display (rows 25,27) is a single topomap with boxed cluster electrodes, a *** tag and a cluster/p-value table — no raster, no per-channel order, no 8-bin strip.
- Captions always state the test, the software and the window ("cluster-based permutation tests ... BESA Statistics 2.1", rows 5,7,16,17,21).
