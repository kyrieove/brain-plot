# Survey: MNE-Python cluster-permutation result figures (2026-10-11)

Scope: sensor-space ERP/EEG/MEG (channel × time) cluster-permutation / TFCE result figures only (no source-space, no
time-frequency, no decoding) whose methods state that the cluster test itself was run in MNE-Python — by naming one of
`permutation_cluster_test`, `permutation_cluster_1samp_test`, `spatio_temporal_cluster_test`,
`spatio_temporal_cluster_1samp_test`, or by attributing the cluster test to MNE(-Python) (MNE's cluster functions / MNE's
TFCE option). Papers that only preprocessed in MNE but ran the cluster test elsewhere (FieldTrip, EEGLAB, BESA,
Eelbrain, SPM, R) were rejected. Rows were found by searching open-access full text on Europe PMC for the MNE cluster
function names and for "MNE-Python" + "cluster-based permutation", reading each candidate's methods sentence and figure
caption, then keeping it only if the caption/methods confirm the figure shows that result; every DOI was resolved on
Crossref (title + first author matched), every paywalled-family article was read through its free PMC page, and every
image was downloaded from the PMC/publisher/tutorial page and opened. Two rows are MNE's own tutorial pages (URL +
access date). Column set follows `survey.md`; two columns are added: `MNE evidence` (a < 15-word quote from the methods
naming MNE and the cluster test, plus the MNE version when stated) and `MNE-native display` (whether the figure looks
like MNE's own plotting or was re-drawn/composited).

## Takeaways for the columns layout
- Group the raster into three stacked panels — Left / Midline / Right — exactly like MNE's own tutorial figure (row 19); brain-plot's single grouped raster can copy that panel split, per-panel channel labels and the "% of points masked" note so the reader sees how many samples entered the cluster test.
- Keep the channel names on the y-axis when the montage is small (~30 channels): rows 1, 5, 6 and 7 all show legible electrode labels, whereas a 64-channel raster (row 6 right panel) is unreadable — brain-plot's ~30-channel columns figure is in the legible range, so keep the names.
- Mark the cluster as a thin black/white contour outline over the raster rather than only recolouring significant samples (rows 1, 5, 6, 7, 19); that is the one gesture every MNE-user raster figure shares.
- Put a companion map next to/above each raster that encloses the cluster with a contour and dots the significant channels (rows 4, 7, 9, 10, 14, 17, 18, 20) — 10 of 20 rows mark channels with a dot, so a small "cluster sensors" map belongs in the columns layout.
- Print the cluster time window (and p-value) as text on the figure when it is known (rows 10, 14, 17, 18); only row 10 prints p-values, so this is an easy way to out-inform current MNE-user figures.
- Use a diverging blue–white–red colourbar centred on 0 for amplitude/t values (rows 1, 5, 6, 7, 12, 15, 19); this is the dominant choice and matches brain-plot's house colourbar.
- Add a cluster-mean waveform (mean or RMS over the significant channels) with the cluster window shaded (rows 17, 18, 20) — three rows pair the raster/topomap with exactly this summary curve, and it is missing from brain-plot's columns figure.
- Choose topomap latencies from the cluster window, not arbitrary bins: 8 of 20 rows place topomaps at the significant-time window (rows 3, 4, 7, 10, 14, 15, 17, 20) while only 5 use fixed bins (rows 5, 8, 11, 12, 16); brain-plot's 8 topomaps should still show even 100-ms bins, but flag the cluster window.
- Keep the topomap row short (3–4 maps, rows 5, 7, 8, 12, 15) and align it to the raster's time axis; stacked long series (rows 12, 15) work but a 4-map strip reads faster.
- Shade the significant interval on any ERP waveform with a grey/orange band (rows 2, 8, 10, 13, 14, 16) — this is the second-most common MNE-user gesture and pairs naturally with the columns layout's waveform row.
- State the colourbar unit explicitly (µV for amplitudes, t/F for statistics, rows 1–20); MNE-user figures never leave the colourbar unlabelled, and it disambiguates raster vs topomap scales.
- Follow the house style of survey.md for the rest of the columns (channel order, marker shape, comparisons), since the MNE-user figures add only the contour/dot/p-value habits above.

## Dropped
- Rahimi 2022, NeuroImage (10.1016/j.neuroimage.2021.118768) — the sensor-level cluster test is named in MNE, but the published cluster figure (Fig. 4) renders the result on cortical surfaces (source space) → out of scope.
- Orpella 2024, Neurobiology of Language (10.1162/nol_a_00138) — the whole-brain ERF cluster figure shows source-space cortical maps, not sensors → out of scope.
- Zhu 2024, PNAS Nexus (10.1093/pnasnexus/pgae535) — names `permutation_cluster_1samp_test`, but Fig. 2 (MEG evoked responses) does not render the cluster result (only peak-amplitude/latency panels) → dropped.
- Shang 2026, Journal of Memory and Language (10.1016/j.jml.2025.104712) — names `permutation_cluster_1samp_test`, but all published figures are behavioural/regression → dropped.
- Koevoet 2026, PLOS Biology (10.1371/journal.pbio.3003779) — names `permutation_cluster_1samp_test from the mne package`, but the figures show representational-similarity analyses only → dropped.
- Studenova 2023, eLife (10.7554/elife.88367) — names `mne.stats.spatio_temporal_cluster_test`, but the result figures are alpha-band/correlation and the only candidate cluster map is 727 × 289 px (< 300 px) → dropped.
- Okamoto 2026, IBRO Neuroscience Reports (10.1016/j.ibneur.2026.05.013) — sensor-space cluster procedures implemented in MNE-Python, but no suprathreshold cluster was found and the figure is descriptive → dropped.
- Ma 2026, Behavioral Sciences (10.3390/bs16081301) — the cluster figure is sensor-space, but the methods attribute only preprocessing (not the cluster test) to MNE-Python → fails the criterion.
- Hong 2026, Brain Sciences (10.3390/brainsci16020174) — MNE-Python is named for EEG preprocessing only; the spatiotemporal cluster test is not attributed to a toolbox → fails the criterion.
- Lin 2026, Cerebral Cortex (10.1093/cercor/bhag110) — cluster test implemented in MNE-Python, but the clusters are on alpha-band power (time-frequency) → out of scope.
- Gautier 2025, Psychophysiology (10.1111/psyp.70206) — MNE cluster analysis on the heartbeat-evoked potential, but the published figures show topographies/waveforms without the cluster result rendered → dropped.
- Frequency/decoding/source candidates that name the MNE cluster functions but show the wrong result type (e.g. Muller 2025, Neuroscience of Consciousness; Geva 2025, Scientific Reports — theta power; Zhang 2024, PLOS Biology — RSA/coherence; Legrand 2022, iScience; Koevoet/Shang as above) → out of scope.
