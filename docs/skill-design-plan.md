# 认知神经科学 ERP 绘图 skill：总体设计方案

状态：设计草案，供用户与 Claude 审查。阶段 2 的正式检索尚未开始。

## 已确认的目标

- 第一版面向认知神经科学论文，参考 Cognition、NeuroImage 等期刊的实际图件，不预设 Nature 风格。
- 主要输入为 MNE `Evoked` 对象或 `-ave.fif` 文件；表格数据只有在通道位置与单位明确时才可用于头皮图。
- 第一版交付三类可复用图件：时间窗 ERP 头皮图、条件或差异波形、波形与对应头皮图的联合图版。
- 交付简短的 `SKILL.md`、可运行绘图工具、示例和图件检查流程，不开发完整 Python 包。
- 第一版的“brain plot”指 EEG 传感器层面的头皮电位图。源定位、皮层表面图、fMRI 图另列后续模块；不能从头皮图直接声称皮层激活位置。

## 第一版的科学与图形检查

- 核对通道名称、类型、位置、坏道与 montage；缺失位置时不猜测头皮分布。
- 明确参考方案、基线、单位、条件名称、差异方向、时间锁定事件与时间窗；不从图形自动推断这些实验参数。
- 时间窗头皮图说明是单时间点还是区间均值；同一比较中的色标范围和零点保持可比，并标出电位单位。
- ERP 波形清楚标注时间与电位单位、零点、所选电极或 ROI、极性方向；统计显著性与不确定性只在具备相应输入时呈现。
- 输出保留可编辑文本和矢量元素，检查图注、面板对齐、标签遮挡、色彩可辨性与最终物理尺寸。
- 极性、配色、时间窗宽度和具体期刊尺寸暂不在设计阶段预设。先依据阶段 2 证据和用户的目标期刊确定。
