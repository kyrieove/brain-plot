## Localisation (collapsed localizer)
11. Every subject equal weight, every condition equal weight; the condition difference is never looked at (rule S3).
    Subject-equal weighting keeps the localizer orthogonal to group differences with unequal n.
12. Priors (name, polarity, search range): study notes / preregistration first, else a built-in component table whose
    every entry is verified with `paper-lookup` before it is written.
13. Per component: (1) extremum of the expected polarity over all EEG channels except reference channels × search range
    → peak channel and latency; (2) window = full width at half maximum of the peak channel's collapsed waveform,
    clipped to the search range; (3) ROI = peak channel + adjacent channels (MNE adjacency) of the same polarity with
    ≥ 70 % of the peak amplitude, at most 6; (4) 1000 subject bootstraps: stable if the latency 95 % CI ≤ 50 ms and the
    peak channel lies in the ROI in ≥ 80 %; else literature window, flagged.
14. Evidence figures mark the ROI channels (paper figures keep rule L11: no marks). The user confirms before any paper
    figure.
